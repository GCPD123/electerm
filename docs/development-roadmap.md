## 建议开发顺序

### 阶段 A：项目治理基础

- 建立 AGENTS、架构、路线图、上游同步和 ADR 文档。
- 固化一个功能一个会话、一个分支、先方案后实施的流程。
- 用户审核后合并文档到 `codex/smartterm-main`。

### 阶段 B：RAG 可验证语料与最短闭环（当前最高优先级）

- 首批语料固定为仓库外 `SPNdocs/SPN命令行.xlsx`，覆盖 SPN650/SPN690E，并建立不少于 20 个黄金问题。
- 完成本地导入、解析、切片、索引、检索和引用展示。
- 首先接入 Ask，只生成带依据的回答和候选命令；Ask 不主动执行，复制或点击既有运行按钮均由用户决定。
- 详细范围和验收见 [RAG 模块 MVP](features/rag-module-mvp.md)。

### 阶段 C：Agent RAG 接入

- 增加只读 `search_fiberhome_knowledge` 工具。
- FiberHome 设备操作先检索证据，再生成命令。
- 展示来源、型号/版本适用性和无可靠依据时的拒答。

### 阶段 D：最低必要的执行控制

- 建立统一的动作提议、策略判断和执行网关。
- 内置 Agent、Ask 代码块、MCP 前台/后台命令全部接入同一入口。
- 未被当前授权档位或用户明确批准的动作保证终端零写入；严重风险默认拒绝。
- 保留 Ask/Agent 产品边界，并为 Agent 建立“请求批准、替我审批、受控完全执行”三档会话级策略。
- 第一版默认“请求批准”；“替我审批”只自动放行明确低风险只读命令；“受控完全执行”必须由用户显式开启并绑定当前会话、固定目标、动作范围和有效期。

### 阶段 E：完整执行体验

- 命令卡片展示目的、目标设备、命令、风险和理由。
- 支持批准、编辑、拒绝、取消。
- 支持查看和随时降低当前 Agent 授权档位；提升权限时展示范围与风险，切换目标后授权失效。
- 显示自动批准原因；支持“仅本次/当前会话”批准、一键降级和撤销。
- 采集命令级输出、退出码、超时和等待输入状态，并让 AI 解释结果。

### 阶段 F：设备能力与审计

- 设备资产/标签、命令适配、配置备份和巡检。
- 追加式执行审计、策略版本和组织控制。
- 在证据充分后再讨论批量或受控自动执行。

## 暂不安排

- 重写 SSH、终端模拟器或 SFTP。
- 高风险无人值守执行。
- 在安全执行网关完成前直接扩展 Agent 自动操作范围。
- 在真实语料和黄金问题尚未准备好时先建设复杂向量基础设施。
- 未取得官方资源前发布低清或 AI 重绘的 FiberHome Logo。

## 每个功能的标准流程

```text
明确结果
→ 新建聚焦会话
→ 从 codex/smartterm-main 建功能分支
→ 阅读 AGENTS 与相关文档
→ 方案/边界/测试经确认
→ 小步实施与针对性测试
→ 差异审查和用户验收
→ 清晰提交
→ 合并产品主线
```
