# ADR-005：Agent 由编排层实际派发终端命令

- 状态：已决定（执行策略由 ADR-007 更新）
- 日期：2026-08-04

## 背景

部分模型会在文本中声称“正在执行命令”，但没有返回 `send_terminal_command` 工具调用。此时终端没有任何输入，用户却只能看到模型的说明，无法区分实际执行和文字承诺。

## 决策

Agent 收到明确的查看/查询意图后，仍可由编排层在模型规划前调用既有 `send_terminal_command` 工具，确保用户看到真实工具卡和执行结果。RAG 预检继续用于提供知识和来源，但在当前 MVP 的 unrestricted 模式下，不再作为命令执行拦截门槛。

## 后果

“查看 ISIS 路由表”这类 Agent 请求不再依赖模型是否主动发起工具调用。当前 Agent 命令策略允许用户要求的命令直接进入终端；Ask 模式仍保持只检索和解释，不主动写入终端。后续如恢复安全约束，以 ADR-007 所述的集中策略入口为准。
