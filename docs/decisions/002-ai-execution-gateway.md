# ADR-002：AI 变更型操作必须经过统一执行网关

- 状态：方案已接受，尚未实现
- 日期：2026-08-02

## 背景

Electerm 已具备内置 Agent、Ask 代码运行、MCP 命令和终端执行能力，但安全校验分散：内置 Agent 和 Ask 可直接执行，MCP 后台命令也可绕过前台校验。只给某一个入口增加确认框不能形成可靠边界。

## 决策

- 建立统一 `Execution Gateway`，作为所有变更型终端/SFTP 操作的唯一入口。
- Agent、Ask、MCP 和未来企业自动化使用相同的动作提议、目标快照、风险判断、审批和结果模型。
- 第一版所有命令都必须显示卡片并由用户点击执行；严重风险默认拒绝。
- 编辑命令或改变目标后必须重新评估，旧批准失效。
- 终端输出经过命令边界、限长和脱敏后才能回传模型。
- 提示词 guardrail 和正则黑名单只能作为辅助规则，不能替代代码级强制策略。

## 影响

现有 Agent 循环、工具 schema、终端适配和会话 UI 可以复用，但所有直接调用终端写入的入口都要逐步收口。MCP 审批可能需要异步请求 ID，避免长时间占用 HTTP/IPC。

详细源码证据、风险分级和阶段计划见 [AI 命令执行研究](../research/ai-command-execution-study.md)。
