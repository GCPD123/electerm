# ADR-007：MVP Agent 命令执行暂时采用 unrestricted 模式

- 状态：已决定
- 日期：2026-08-06

本决策覆盖此前文档中关于 Agent 命令必须只读、必须有可靠 RAG 证据、必须匹配 CLI 或必须人工复核的执行限制；Ask 只读边界不被覆盖。

## 背景

真实设备测试中，Agent 的命令策略频繁因为 RAG 证据、命令前缀、敏感读取、参数模板、CLI 识别和终端状态而拒绝执行，影响了 MVP 的实际验证。

## 决策

在用户明确要求下，当前 MVP 的 Agent 命令执行策略切换为 `unrestricted`：

- `send_terminal_command` 不再因为命令不在知识库、命令包含参数、命令属于配置/敏感读取或 CLI 无法识别而拦截；
- RAG 仍可提供知识、解释和来源，但不再作为执行权限门槛；
- 用户要求执行的命令由 Agent 直接交给现有终端工具；
- Ask 模式仍保持只检索、解释和生成候选，不主动写入终端；
- 策略仍集中在 `agent-execution-policy.js` 一个入口，后续恢复安全约束时只需要重新实现该入口，不需要重写 Agent 工具链。

## 使用边界

这是当前 MVP 的主动取舍，不代表最终发布版的安全方案。真实设备上使用时，用户需要自行确认当前终端、命令内容和命令影响范围。后续如需恢复约束，应增加明确的用户可见模式开关，而不是再次静默拦截。
